# Weekwell

A responsive student planning website with an interactive weekly planner and study, note taking, and planning guides.

## Publish with GitHub Pages

1. Create a new public repository on GitHub.
2. Upload the files in this folder to the repository root. Keep index.html at the root.
3. Open Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then save.
5. After deployment finishes, the public site link will appear in the Pages settings.

The planner saves commitments and assignments in each visitor browser using local storage.
